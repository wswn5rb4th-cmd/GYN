Backup na nuvem

Configure seu projeto Supabase para sincronizar os registros entre dispositivos. As credenciais ficam neste navegador, não no código público.

Nuvem não configurada.
Configuração necessária (uma vez)

No Supabase, crie uma tabela chamada gyn_backups com colunas user_id (uuid, primary key, referência auth.users.id), payload (jsonb, not null) e updated_at (timestamptz, default now()). Ative RLS e crie políticas SELECT, INSERT e UPDATE para authenticated usando user_id = auth.uid(). A publicação de site estático não pode criar essa configuração por você.

create table public.gyn_backups (user_id uuid primary key references auth.users(id) on delete cascade, payload jsonb not null, updated_at timestamptz not null default now()); alter table public.gyn_backups enable row level security; create policy gyn_backups_select on public.gyn_backups for select to authenticated using (auth.uid() = user_id); create policy gyn_backups_insert on public.gyn_backups for insert to authenticated with check (auth.uid() = user_id); create policy gyn_backups_update on public.gyn_backups for update to authenticated using (auth.uid() = user_id) with check (auth.uid() = user_id);
